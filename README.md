## Project Overview

This repository contains the code developed for the thesis *Enhancing ShakeMaps using crowdsourced smartphone data and macroseismic information through spatial statistical modelling*. It includes the full workflow for processing seismic datasets (PGA, PSA, CPGA), performing data cleaning, implementing the SM-LGP spatial model using D-STEM, validating performance, and generating ShakeMap predictions for the Campi Flegrei 2025 event.

All scripts are provided to reproduce the analyses, modelling steps, and spatial outputs discussed in the thesis.
